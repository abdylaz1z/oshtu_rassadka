# Students Day — рассадка гостей

Сайт для отметки рассадки в ресторане: круглые столы, при нажатии стол «увеличивается», стулья вращаются вокруг него.
Нажимаете на стул — гость сел. Когда сели все, стол становится золотым и помечается «Заполнен».
Можно добавлять и убирать стулья, добавлять новые столы. Несколько человек могут отмечать столы одновременно.

Сайт статический (HTML + CSS + JS), сборка не нужна. Общие данные хранятся в **Firebase Realtime Database** (бесплатно).

## 1. Запуск без базы (проверка)

Модули браузера не работают с `file://`, поэтому запустите любой локальный сервер:

    npx serve .

Без заполненного `config.js` сайт работает в локальном режиме: данные только в вашем браузере.

## 2. Подключение общей базы (Firebase)

1. Откройте https://console.firebase.google.com и создайте проект.
2. **Build → Realtime Database → Create database**. Выберите регион, режим «Locked mode».
3. Вкладка **Rules**: вставьте содержимое `database.rules.json` и нажмите **Publish**.
4. **Project settings → General → Your apps → Web (</>)**: зарегистрируйте приложение и скопируйте значения.
5. Впишите их в `config.js` (нужны `apiKey`, `databaseURL`, `projectId`, `authDomain`).

Данные хранятся по путям `tables/t<номер>/s/<стул>`, поэтому два человека за разными столами
(и даже за одним, но на разных стульях) не перезаписывают друг друга.

### Безопасность

Правила из `database.rules.json` открыты: любой, у кого есть ссылка на сайт, может менять рассадку.
Для одного мероприятия этого обычно достаточно. Чтобы закрыть доступ от посторонних:

1. В Firebase: **Authentication → Sign-in method → Anonymous → Enable**.
2. В правилах замените `true` на `"auth != null"`.
3. В `config.js` поставьте `anonymousAuth: true`.

## Настройка схемы

В `app.js`:
- `defCap` — вместимость столов по умолчанию (12 или 14),
- `LBL` — подписи факультетов над столами,
- `pos` — положение стола на схеме.
Столы 1–17 слева, 18–33 справа, «Невеста» сверху, «Сцена» снизу.
